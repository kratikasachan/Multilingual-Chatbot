# Multilingual Chatbot

A multilingual AI chatbot built with Flask and the Groq API. It replies in the language you write in and can speak the answer aloud.

## Features
- Chat in multiple languages (Hindi, English and more)
- Fast AI replies using Groq
- Simple web interface
- Voice reply in the browser

## How to run
1. Install the requirements:
   pip install -r requirements.txt
2. Create a file named `.env` in the backend folder and add:
   GROQ_API_KEY=your_key_here
3. Start the app:
   python app.py
4. Open http://127.0.0.1:5000 in your browser.

## Tech used
Python, Flask, Groq API, HTML, CSS, JavaScript
